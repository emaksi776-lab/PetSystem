# Тема: «Учёт животных в приюте»
### Предметная область 
Система предназначена для учета количества животных в приюте и отслеживания их физического и эмоционального состояния.
### Цели системы
Помочь работникам следить за животными, давать врачам полную информацию о симптомах болезней животных, для администрации - управлять доступом сотрудников.
### Задачи
- Регистрация сотрудников
- Постановка животных на учет
- Ведение учета здоровых и больных животных
- Запись симптомов больных
- Напоминания о требованиях к животным – определенное количество корма, прием лекарств
- Отслеживание эмоционального состояния животных
- Закрепление за животным человека, который хочет его забрать
### Пользователи системы 
Администратор, рабочие по уходу, ветеринары

- **Роль администратора:**  
    - Регистрация сотрудников, управление правами доступа  
- **Роль рабочих по уходу:**   
    - Отслеживание физического, эмоционального состояния животных
    - контроль своевременного приема лекарств животными
    - запись симптомов болезней животных
    - обновлять информацию о наличии потенциального хозяина  
- **Роль ветеринаров:**  
    - Регистрация животных в системе(создание их карточки)
    - отслеживание физического состояния животных
    - выписывание лечения больным  

### Функции системы
- Администрирование - регистрация сотрудников, разграничение прав доступа
- Хранение данных
- Напоминания - отправка уведомлений о кормлении и приеме лекарств
- Учет животных - создание карточки животного, редактирование данных, просмотр списка животных, ведение истории болезней
- Закрепление нового хозяина за животным
